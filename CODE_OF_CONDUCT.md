# Kodeks postępowania / Code of Conduct

Chcemy, żeby udział w projekcie był przyjazny dla każdego, niezależnie od doświadczenia,
poglądów politycznych, płci, wieku, niepełnosprawności, pochodzenia czy wyznania.

- Pisz rzeczowo i życzliwie. Krytykuj kod i argumenty, nie ludzi.
- Bez nękania, obelg, treści seksualnych, gróźb i publikowania cudzych danych osobowych.
- Projekt dotyczy polityki, ale zgłoszenia i pull requesty nie są miejscem na agitację
  ani spory partyjne. Rozmawiamy o danych i o kodzie.

Opiekunowie mogą usuwać komentarze, zamykać wątki i blokować osoby, które łamią te zasady.
Naruszenia zgłaszaj prywatnie przez [leniwyposel.pl/kontakt](https://leniwyposel.pl/kontakt/).

Zasady opierają się na [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

---

**English.** Be respectful and constructive; criticise code and arguments, not people. No
harassment, insults, sexual content, threats or doxxing. This project is about politics, but
issues and pull requests are not a place for campaigning or partisan disputes. Maintainers may
remove comments, lock threads and block people who break these rules. Report violations
privately via [leniwyposel.pl/kontakt](https://leniwyposel.pl/kontakt/). Based on the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
